# Homebrew tap for Warren

```sh
brew install veerareddyvishal144/warren/warren
```

Installs `warren`, `warrend`, `warren-mcp` and `warren-gateway` from the [Warren releases](https://github.com/veerareddyvishal144/warren/releases). The formula is generated from `packaging/homebrew/warren.rb` in the main repository on every release.
